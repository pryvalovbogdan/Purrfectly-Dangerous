# Simon the Dragon Slayer

A 2D side-scrolling auto-runner for iPhone. Run, jump trees and goblins, level up into a fireball,
and beat a boss at the end of each of four levels: a frost giant chief, an ice wyrm, a pale queen
and the tempest lord.

Swift + SpriteKit, no third-party runtime dependencies. All pixel art and sound effects are
generated by scripts in `Tools/`.

## Run it

```
brew install xcodegen
python3 -m venv Tools/.venv && Tools/.venv/bin/pip install pillow pytest
xcodegen generate && open SimonTheDragonSlayer.xcodeproj     # then Run on an iPhone simulator
```

or from the command line: `Tools/run-sim.sh` (menu) / `Tools/run-sim.sh 1 7 28 39` (a bot plays
level 1 and screenshots are saved to `.build/screens/`).

Plays in landscape or portrait. Controls: tap to jump (hold for higher), tap the right side to throw a fireball once unlocked,
hold and release there for a charged one.

## Check it

`Tools/check.sh` runs the rule tests, proves every level can be finished without taking a hit,
tests the generated art and builds the app.

## Names

Every name shown in the game lives in `App/Resources/Lore.json`, keyed by neutral ids; code and
asset names never contain display names. `Tools/release-check.sh` is the gate before any upload.
